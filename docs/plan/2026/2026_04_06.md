### 1. 系统学习go

::: info 目标
能用go写完整的业务需求，并能设计基于go的高并发等大流量场景
:::

::: tip 要求
督促自己古法编程（ai提效是提效，但是排查问题还是需要基于历史经验）；了解go组件底层；
:::

::: details 意义
之后大概率go会是一种趋势，之后接触的业务，以及新业务线大概率是go写的。
:::

---

### 2. 深入mysql底层

::: info 目标
能了解一般的mysql的疑难杂症，以及库表设计的经验。
:::

::: tip 要求
能够在10min内快速分析出某个业务怎么建表，某个表怎么加索引。
:::

::: details 意义
实现高`人效比`的条件之一是判断力在线，尤其是ai加持下的开发。
:::

---

### 3. agent开发探索

::: info 目标
能理解掌握agent开发的基本原理和路线，并且能在工程进行迁移。
:::

::: tip 要求
能在10分钟内给普通人讲清楚什么是agent，如何利用llm去实现一个简单的agent。
:::

::: details 意义
向ai靠拢，从底层开始迁移开发思维，另外培养自己在`battle`这块的能力。
:::

---

### 4. 业务能力level1

::: info 目标
基本掌握和理解自己负责的业务，熟悉其**产品架构**，发展阶段，变现模式，现阶段瓶颈。
:::

::: tip 要求
能够自己复现出一个小的业务模型，归纳出可以复用的产品模型和技术模型，能够清晰的讲出目标所包含的点。
:::

::: details 意义
更好的深耕业务和技术，把自己绑定在公司业务中。（level2：用level1的时间，了解2+其他模块的业务模型，此条待定，因为可能涉及权限等相关的障碍）
:::
